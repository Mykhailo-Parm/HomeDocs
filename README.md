# HomeDocs

Домашний архив документов: кладёшь сканы во «Входящие», ИИ читает их и предлагает название, тип (счёт, информация, договор…), человека из семьи, дату и сумму. Ты проверяешь в веб-интерфейсе и одним нажатием раскладываешь по папкам `archive/Человек/Тип/`.

- Оригиналы **никогда не удаляются и не переименовываются**: при подтверждении файл копируется в архив.
- Новые имена получателей добавляются в список людей автоматически.
- ИИ сменный: `gemini` (бесплатный ключ), `ollama` (локальная модель, без интернета) или `claude`.
- Работает с папкой на компьютере; тот же код потом запускается на мини-сервере (Raspberry Pi и т.п.).
- Уже есть `POST /api/upload` — через него позже сможет загружать файлы приложение на телефоне.

## Запуск на Windows

1. Установи Python 3.11+ с python.org (при установке отметь «Add Python to PATH»).
2. В папке проекта:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   copy config.example.toml config.toml
   ```
3. Открой `config.toml`: выбери провайдера и впиши ключ (Gemini: бесплатный ключ на aistudio.google.com) или установи Ollama.
4. `python -m homedocs`, затем открой http://localhost:8000
5. Клади PDF/фото/txt в папку `inbox` и нажимай «Сканировать».

## Сканы без текста
Gemini и Claude читают сканы и фото напрямую. Локальная модель (Ollama) пока читает только PDF с текстовым слоем; OCR для неё — следующий шаг.

## Конфиденциальность
Gemini/Claude получают содержимое документов через интернет. Для полностью локальной работы выбери `ollama`. По умолчанию сервер слушает только `127.0.0.1`; для доступа с других устройств задай `HOMEDOCS_HOST=0.0.0.0` (добавь пароль/VPN до этого, они пока не реализованы).
