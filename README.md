# HomeDocs

Домашний архив документов: кладёшь сканы во «Входящие» (или перетаскиваешь файлы прямо в браузер), ИИ читает их и предлагает название, тип, статус (к оплате, оплачено…), человека из семьи, дату, сумму и срок. Ты проверяешь в веб-интерфейсе и одним нажатием раскладываешь по папкам `archive/Человек/Тип/`.

- Главный экран — **рабочий стол** с настоящими папками архива на диске: открывай папки, создавай и переименовывай их, перетаскивай документы в папки (документ из «Входящих» при этом сразу раскладывается туда). Есть и вид списком с фильтрами.
- **Корзина:** удалённые документы (и оригинал, и копия в архиве) переносятся в папку `trash/` и возвращаются одним нажатием. Окончательное удаление с диска — только с подтверждением: нужно переписать 3 случайные цифры с экрана.
- При подтверждении файл **переносится** из «Входящих» в архив, так что во «Входящих» остаётся только то, что ещё не разобрано. (Оригиналы, оставшиеся во «Входящих» от старой версии, где файл копировался, удаляются при запуске, если в архиве лежит побайтово такая же копия.)
- Документы показываются **карточками с превью первой страницы** (PDF, фото, текст), под ним — название, человек, тип, дата, сумма, срок и статус. Превью создаются один раз и хранятся в `data/thumbs/`.
- **Все документы** — карточки или таблица (переключатель) по всему архиву: сортировка по любой колонке, фильтры по человеку, типу, статусу, состоянию и датам, поиск, экспорт в CSV, колонка с папкой (клик открывает её на рабочем столе).
- Имена файлов и папок в архиве всегда латиницей (украинский и немецкий транслитерируются: `Михайло Парм` → `Mykhailo Parm`, `Städt.` → `Staedt.`).
- Типы и статусы настраиваются (⚙ → Типы / Статусы); ИИ сам добавляет новые, если ничего не подходит (помечены «AI»).
- Интерфейс на английском, украинском и немецком; светлая/тёмная/системная тема.
- Вход по паролю, несколько пользователей семьи.
- ИИ сменный: `gemini` (бесплатный ключ), `ollama` (локальная модель, без интернета) или `claude`.

## Запуск на Windows

1. Установи Python 3.11+ с python.org (при установке отметь «Add Python to PATH»).
2. В папке проекта:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   copy config.example.toml config.toml
   ```
3. Открой `config.toml`: выбери провайдера и впиши ключ (Gemini: бесплатный ключ на aistudio.google.com) или установи Ollama.
4. `python -m homedocs`, затем открой http://localhost:8000
5. При первом открытии создай учётную запись (только с этого компьютера) — она станет администратором.
6. Перетащи файлы в окно браузера или положи PDF/фото/txt в папку `inbox` и нажми «Scan inbox».

### Автозапуск на Windows
Чтобы HomeDocs сам запускался при входе в Windows (без окна консоли, с перезапуском через 5 секунд после любого сбоя):
```
powershell -ExecutionPolicy Bypass -File scripts\windows\install-autostart.ps1
```
Убрать: `scripts\windows\uninstall-autostart.ps1`. Лог работы — `data\homedocs.log`. Задача видна в «Планировщике заданий» под именем HomeDocs. Пока ноутбук спит, сервер недоступен; после пробуждения работает дальше.

Клавиши: `/` поиск, `↑ ↓` следующий документ, `Esc` закрыть панель, `Ctrl+S` сохранить, `Ctrl+Enter` принять и разложить.

## Сканер с телефона

Страница `/scan.html` (кнопка «📷 Scan» в шапке) — сканер в браузере телефона, как Adobe Scan:
- фотографируешь страницы (или выбираешь из галереи) — сервер сам находит лист, выпрямляет перспективу с настоящими пропорциями листа, убирает тени и делает белый фон;
- углы можно поправить пальцем (с лупой), фильтры: «Документ» (белая бумага, цвет печатей сохраняется), «Чёрно-белый», «Серый», «Оригинал»; поворот;
- несколько страниц собираются в один PDF во «Входящих» и сразу разбираются ИИ (и OCR).
- На телефоне: «Добавить на главный экран» — откроется как отдельное приложение.

Чтобы телефон видел сервер, его нужно открыть в сети (по умолчанию HomeDocs виден только с этого компьютера):
- **Лучше всего — Tailscale** (бесплатный VPN): поставь на ноутбук и телефон, войди в один аккаунт. Связь зашифрована и работает откуда угодно. `tailscale serve --bg 8000` даёт адрес https://…ts.net — тогда сканер ставится как полноценное приложение.
- **Только дома по Wi‑Fi:** запуск с `HOMEDOCS_HOST=0.0.0.0`, на телефоне открыть `http://<IP ноутбука>:8000/scan.html`. Без шифрования — не делай так в школьной или публичной сети.

## OCR (распознавание текста на сканах)
OCR (Optical Character Recognition) превращает скан или фото в настоящий текст — на этом компьютере, без интернета. Используется [Tesseract](https://github.com/tesseract-ocr/tesseract) с языками украинский, немецкий, английский, русский.

- При сканировании PDF без текстового слоя и фото распознаются автоматически; текст виден в карточке документа («Текст документа») и находится поиском.
- Gemini/Claude по-прежнему получают сам скан (так точнее), а локальная модель Ollama работает с распознанным текстом — так можно разбирать сканы полностью без интернета.
- Документы, добавленные до установки OCR: ⚙ Настройки → OCR → «Распознать N документов». Один документ: кнопка «Распознать текст (OCR)» в карточке.
- Перевёрнутые листы и фото с телефона поворачиваются автоматически.

Установка Tesseract:
- Windows: `winget install UB-Mannheim.TesseractOCR`, затем положить `ukr.traineddata`, `deu.traineddata`, `rus.traineddata` (из [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast)) в папку `C:\Program Files\Tesseract-OCR\tessdata`.
- Debian/Ubuntu: `apt install tesseract-ocr tesseract-ocr-ukr tesseract-ocr-deu tesseract-ocr-rus`.
- Настройки — раздел `[ocr]` в `config.toml`. Состояние видно в ⚙ Настройки → OCR.

## Безопасность и приватность

Что уже сделано в приложении:
- Вход по паролю (хеш scrypt), сессии в HttpOnly/SameSite=Strict cookie на 30 дней, смена пароля выходит со всех устройств.
- Не больше 5 неудачных попыток входа за 15 минут с одного адреса.
- Первый (админ) аккаунт можно создать только с самого компьютера, где запущен HomeDocs.
- Защита от CSRF (обязательный заголовок), строгая Content-Security-Policy, запрет встраивания чужими сайтами.
- Файлы отдаются только из папок «Входящие» и «Архив», и только вошедшим пользователям.
- По умолчанию сервер слушает только `127.0.0.1` — из сети его не видно.
- `config.toml` с ключами и папки `data/`, `inbox/`, `archive/` исключены из git.

Что сделать самому:
1. **Шифрование диска.** Windows 11 Home: «Параметры → Конфиденциальность и защита → Шифрование устройства» (если пункт есть). Если нет — VeraCrypt: зашифрованный контейнер, внутри него держи `inbox`, `archive` и `data`. Без шифрования любой, кто получит диск/ноутбук, прочитает файлы, пароль приложения не поможет.
2. **Пароль на учётную запись Windows** и блокировка экрана.
3. **Резервные копии** по правилу 3-2-1, зашифрованные (например, restic или Duplicati с паролем): одна копия дома на внешнем диске, одна вне дома.
4. **ИИ видит содержимое документов.** Бесплатный Gemini API может использовать запросы для улучшения моделей Google. Для паспортов, медицины и т.п. лучше платный тариф Gemini/Claude (данные не используются для обучения) или локальная Ollama.
5. Ключи API не отправляй в чаты/почту; если отправил — пересоздай.

## Свой сервер в будущем

Рекомендуемый вариант — **маленький домашний сервер**, а не арендованный в интернете (документы остаются дома):
- **Железо:** мини-ПК на Intel N100 (≈150–200 €, 16 ГБ RAM, SSD) — тихий, ≈10 Вт. Raspberry Pi 5 + SSD тоже подойдёт, но слабее для локальной ИИ-модели.
- **Система:** Debian или Ubuntu Server с **полным шифрованием диска (LUKS)** при установке.
- **Доступ извне — только через VPN:** [Tailscale](https://tailscale.com) (бесплатно для семьи) — телефон и ноутбук видят сервер, а из интернета он не виден вообще. Никаких проброшенных портов на роутере.
- **HTTPS:** Caddy как обратный прокси (или `tailscale serve`, он сам выдаёт сертификат). Запуск: `HOMEDOCS_HOST=127.0.0.1` за прокси.
- **Автозапуск:** systemd-служба или Docker.
- **Обновления:** `unattended-upgrades` для автоматических обновлений безопасности.
- **Бэкапы:** restic → внешний диск + облако (Backblaze B2 / Hetzner Storage Box), зашифрованные.
- **Вход по SSH** только по ключу, пароль для SSH отключить.

Арендованный VPS (Hetzner и т.п.) проще, но документы будут лежать на чужом сервере — тогда обязательно шифрование и VPN.
